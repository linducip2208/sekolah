# Fonts

Place the **Inter** font files here:

- `Inter-Regular.ttf`
- `Inter-Medium.ttf` (weight 500)
- `Inter-SemiBold.ttf` (weight 600)
- `Inter-Bold.ttf` (weight 700)

Download from <https://rsms.me/inter/> or <https://fonts.google.com/specimen/Inter>.

If you skip this step, remove the `fonts:` block in `pubspec.yaml` to fall back
to the system font.
